与 NJUST 院校管理决策系统

一套面向高校学生工作的一体化数智化系统：把校长、教务处、辅导员、学生四个角色的数据打通， 做到一人一档、一套数据、三级视图，任务下发与反馈形成闭环，AI 智能体为每个学生给出学业与就业建议。 本页是这两个系统的对外介绍与演示入口页。

两个系统，一套底座

NJUST 学生全景档案 AI Agent 面向学生本人，NJUST 院校管理决策系统 面向管理者； 两者共用同一套数据底座与任务通道，学生在手机上看得到的东西，正是辅导员和教务处点一下之后落下去的结果。

NJUST 学生全景档案 AI Agent

面向学生本人的一人一档成长档案。只看得到自己的数据，换别人的学号会被整页拦截。

  • 我的档案：一屏三个数——绩点排名、能力总分、在途预警
  • 我的简历：学校档案自动填入，可打印导出 PDF、复制为文本
  • 学校任务：只显示派给我的（含全班 / 全院 / 全校），完成状态同步给派发方
  • 学业预警：写明触发依据（绩点 / 环比 / 晚归），学生可提交说明申诉
  • 六维能力与就业：能力画像 + 岗位匹配推荐
  • AI 成长助手：由智能体给出学业与就业建议
NJUST 院校管理决策系统

面向校长、教务处、辅导员三级的决策支持系统，一屏看风险、一键把任务派下去。

  • 校长端：全校态势统览、学院风险榜（预警数 / 边缘数 / 合格率）、派发议题
  • 教务处端：各科合格率与环比、问题科目排行、下发整改任务
  • 辅导员端：困难生名单、帮扶台账、回传记录、一键生成周报
  • 任务闭环：派出去 → 交回来 → 看得到，状态点「未回灰 / 已回绿 / 逾期红」
  • 数据同源：换设备、换人打开都是最新状态，不靠刷新

四个端，各管一段

从看数据到派任务再到回传结果，一条链走完，谁也不用再等一份报表。

校长端 · 看全校

六格关键数字一屏看完，往下能钻到学院，发现短板直接把议题派给该院负责人，派完在行末看状态点。

教务处端 · 抓教学质量

各科合格率与环比一目了然，问题科目排行在前；选一门课就能下发整改任务，自动带出对应辅导员。

辅导员端 · 减负

自己带的困难学生名单、最近一次帮扶时间、累计次数、下次跟进时间都摆在台账上，回传与周报各点一下。

学生端 · 看自己

绩点、预警、能力、岗位一处看全；老师的通知和任务直接收到，点「确认完成」对方页面就更新。

系统能力与技术底座

不是一堆静态报表，而是一套能算、能判、能派活、能留痕的学生工作系统。
